# estudos-Kotlin

Repositório dedicado às minhas atividades de estudo da linguagem **Kotlin**. Aqui eu guardo os exercícios conforme avanço no aprendizado, do básico em diante.

## 📚 Conteúdo

| Arquivo | O que aborda |
|---|---|
| `primeiro_cod.kt` | Como iniciar um programa em Kotlin e mostrar o resultado no terminal |
| `segundo_cod.kt` | `var` (mutável) e `val` (imutável) e as formas de declarar variáveis |
| `tipos_primitivos.kt` | Principais tipos usados no Kotlin |
| `conversoes_primitivas.kt` | Conversão entre tipos primitivos, por exemplo String para Int |
| `calculadora.kt` | Exercício prático: uma calculadora simples |
| `interface.kt` | Receber e mostrar textos em interfaces gráficas (`JOptionPane`) |

## ▶️ Como executar

Pré-requisitos: Kotlin (`kotlinc`) e Java (JDK) instalados.

Para rodar um arquivo pelo terminal:

```bash
kotlinc arquivo.kt -include-runtime -d arquivo.jar
java -jar arquivo.jar
```

No VS Code, o projeto tem uma tarefa configurada em `.vscode/tasks.json`. Basta abrir o arquivo `.kt` desejado e pressionar `Ctrl+Shift+B` para compilar e executar.

Praticar a lógica de programação e aprender os fundamentos do Kotlin, registrando a evolução dos estudos nos commits.
